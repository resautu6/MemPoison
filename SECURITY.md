# Security Policy

## Supported Versions

The public branch is a research release. Security fixes are considered for the
current `main` branch and for tagged releases when tags exist.

## Reporting A Vulnerability

Please report security issues privately to the maintainers before public
disclosure. Include:

- affected commit or release
- a minimal reproduction
- expected and observed behavior
- any files or benchmark rows needed to reproduce the issue

Do not include API keys, private model endpoints, proprietary datasets, or
unreviewed experiment outputs in public issues.

## Scope

This policy covers the source code in this repository. Full benchmark releases
and experiment provenance bundles may be published separately and should be
reviewed independently.
